# Fontes infantis do sistema

Fontes baixadas do Google Fonts em 23/07/2026 para uso nas peças das escolas.

| Fonte | Uso |
|---|---|
| Fredoka 600 e 700 | Headlines do Aviãozinho de Papel |
| Baloo 2 600 e 800 | Headlines do Colibri |
| Bubblegum Sans | Anotações curtas, perguntas e detalhes lúdicos |
| Nunito 600 e 800 | Corpo, subtítulos e informações de apoio |

Fontes de referência:

- https://fonts.google.com/specimen/Fredoka
- https://fonts.google.com/specimen/Baloo+2
- https://fonts.google.com/specimen/Bubblegum+Sans
- https://fonts.google.com/specimen/Nunito

Regra: fontes decorativas entram apenas em textos curtos. Parágrafos e informações de apoio usam Nunito para preservar legibilidade.
